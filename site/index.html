Kemori

the terminal IDE that sets itself up

Kemori is a terminal IDE that assumes you would rather be coding than configuring. Open a project and it works out the language, fetches the right language server from a verified source, checks the hash, and offers to install anything missing. Then it runs the real tool to check that the install actually works. No plugin marketplace, no hand-written LSP config, no dotfiles to maintain.

The interesting part is where the complexity went. Language-specific logic never leaks into the editor or the UI. Detection weighs five signals — filename, shebang, extension, content, project context — and a project marker never overrides a file's own nature. Expensive work runs on a background worker, so the interface repaints only when something actually changed. It also never paints an opaque background, so your terminal theme and wallpaper survive.

  • ✦ 27 languages in one table. LSP is optional; offline intelligence is not.
  • ✦ Missing toolchains are fetched, pinned, and verified by running the real tool. A file existing is not the same as a tool working.
  • ✦ Never paints an opaque background. Your terminal theme, blur and wallpaper survive.
  • ✦ A star-cat on the welcome screen. She is not behind your code.

02 Go · GPL-3.0 v0.1 · early

Percy

a small language that compiles itself

Percy is a statically typed, garbage-collected language that compiles ahead-of-time to a real executable — not interpreted, not a bytecode VM. The syntax borrows from C#, the smallness and tooling culture from Go, the ecosystem ambition from Rust. The command-line tool is called purr; the files are .pcy.

No null, no undefined behavior, no implicit conversions, and every match is exhaustive. The toolchain is written in Percy and emits static binaries directly, with no C compiler in the build path. A frozen Go compiler stays behind as the bootstrap and as a differential oracle: the self-hosted stages agree with it byte for byte, down to diagnostics and positions.

  • ✦ Most languages make you choose between small and useful. Percy refuses the trade.
  • ✦ SPEC.md is the source of truth. Undecided things are listed as undecided instead of quietly invented in code.
  • ✦ The self-hosted compiler is compared against the Go reference across thousands of inputs, down to diagnostics and positions.
  • ✦ No null. No undefined behavior. No implicit conversions. Every match is exhaustive.
  • ✦ Toolchain GPL-3.0-or-later; runtime MIT. The code you write in Percy stays yours.

03 Go · GPL-3.0 active

vynl

a DJ booth that fits in your terminal

vynl turns a local music folder into a live DJ console. There is a rotating vinyl rendered from real coordinates, a real FFT spectrum, stereo meters, independent tempo and pitch, and a three-band EQ. It plays MP3, FLAC, WAV, and OGG without a browser, a GUI, or a service in the middle. Built for terminals, not for windows.

Under the deck is a serious audio engine. A bounded four-second PCM ring keeps memory flat; gapless playback joins tracks inside the same audio callback; an optional equal-power crossfade bridges them. The EQ is a Linkwitz-Riley three-way crossover, and a flat EQ stays exactly flat. A corrupt file gets skipped, because one bad track should not wreck the set. Playlists are plain M3U8 files.

  • ✦ A 1024-point Hann-windowed FFT mapped to 48 log-spaced bands, with peak-hold markers.
  • ✦ Gapless playback, an optional equal-power crossfade, and a four-second PCM ring that keeps memory flat.
  • ✦ Vinyl mode couples tempo and pitch like a turntable; ReplayGain, crossfade and EQ change live.
  • ✦ No background colour. Your terminal's theme and opacity show through. Built for terminals, not windows.

04 Rust · GPL-3.0 early

Grimmoire

a dark-fantasy world drawn entirely in glyphs

Grimmoire is an ASCII-first RPG set in a village that survived a drought by feeding the water, and a shrine that has spent four hundred years making sure nobody finishes the sentence that would end it. The wizard arrives nine years after the water stopped coming back. Six connected places, nine characters, twelve journal entries, and one puzzle whose rules are written on the floor.

The renderer is the project. Walls read their neighbours and show lit caps or shadowed bases; floors are textured from world position so they never shimmer; light falls off with distance. Conversations branch on what you know and what you have done — and a couple of choices change a place, not just a line. Also, the scavenger is lying. Remembering that changes what he says next.

  • ✦ ASCII is the identity, not a fallback. No image files, no sprites, no graphics protocol — just glyphs, ink, and light.
  • ✦ Walls read their neighbours; floors are textured from world position so they never shimmer; light falls off with distance.
  • ✦ Conversations branch on what you know and what you have done. The scavenger is lying.
  • ✦ Kitty at 80×24 or larger. Below that it says so and suspends instead of drawing noise.

caelestia-rice

the desktop, dressed in glass

The Linux rice: Caelestia shell over Hyprland, configured in Lua. Launcher, dashboard, sidebar, terminal — everything is frosted glass, and nothing pins a colour. The palette comes from the active wallpaper, so one caelestia wallpaper command re-themes the whole desktop. The installer backs up everything it touches, because a rice should be reversible.

    03 / about

    the short version

    I learn by making
    the thing.

    I'm kiyra. I write software for the terminal because I like being close to the machine, and because a terminal is the only place where a compiler, a record deck, and a haunted village can share the same window.

    I don't have a grand theory of software. I have a habit: when something feels like magic, I take it apart until it stops. That's how Kemori grew a language-server lifecycle, how Percy ended up with a self-hosting compiler, and how vynl ended up with a ring buffer and an FFT.

    Most of this is built alone, in public, usually late. I read issues. I answer email. If you want to talk about compilers, terminal rendering, or why your font looks wrong, the inbox is open.

    If I can't explain why it works, it doesn't work yet.

    05 / notes

    habits & experiments

    Curiosity,
    compiled.

    I don't have a manifesto. I have a few rules that keep showing up in the repos, usually after I learn them the hard way.

    01

    write the spec first

    Percy has a SPEC.md. When code and spec disagree, the spec wins until I deliberately change it. It is a small rule that keeps me from inventing a language by accident.

    02

    compare against the boring version

    The self-hosted compiler isn't trusted because it works. It's checked against the Go reference across thousands of inputs, down to diagnostics and positions. "It runs" is a low bar.

    03

    the interface is the system

    A terminal renderer has to care about character widths, cursor placement, and the cost of a repaint. The polish is not separate from the engineering underneath it.
